XSS 정제 결과를 실제 요청 본문에 반영

문제
  • 필터 내부에서 정제한 문자열이 실제 요청 데이터에 반영되지 않는 구조
원인
  • 문자열을 변경해도 통과 여부만 반환하고 원래 값을 교체하지 않음
해결
  • 중첩 JSON 객체·배열을 재귀 순회해 정제한 값으로 교체
  • 교체한 값으로 요청 본문을 재구성해 업무 처리에 전달
  • 정책을 클래스패스에서 읽고 정책 객체를 1회 준비해 재사용
