# 프로젝트 내용 보강 및 사용자 수정 반영

- 반영일: 2026-10-04.
- 대상: `portpolio` 웹페이지. 기존 디자인·이미지·아키텍처 도식·PDF 유지.
- UI 변경: GIF 이미지에 재생/정지 클릭 동작 연결, GIF 커서만 조정. 기존 상세·흐름도·카드 스타일 재사용.
- 회사 원본 코드·보고서·실제 서버 주소·개인정보는 공개 저장소에 복사하지 않음.

## 제목 및 제거 항목

- 제목: UART 시간 경계 오류, Android–Beacon 인식 문제, Android–Unity 모듈 연동 문제, DB 백업 시 장시간 Thread 점유 문제로 변경.
- CMP 제목: `대량 데이터 조회 시 외부 API 응답 대기로 인한 처리 지연`, `Kubernetes 백업 연동 확장에 따른 테넌트별 정책 조회 문제`.
- 제거: Arabica 복원 날짜·차등 명령 인자, Wallet 계좌 생성·Entity/SQL 매핑·SSE 인증 상태 매핑 사례.
- 제거: 모든 애플리케이션 아키텍처 하단 기술 설명·확대 안내·보조 설명, CONS Unity 실행 화면 캡션, STM·Beacon GIF 캡션·별도 재생 버튼.
- SSE 재조사 기준: 최초 구현과 피드백 후 구조 변경을 구분. 단순 상태명 매핑 수정을 사용자가 요청한 사례로 대체하지 않음.
- DB 재조사 기준: 과도한 외래키 관계와 관련된 구조 변경을 확인. enum 불일치를 동일 사건으로 취급하지 않음.
- 재조사 결과는 공개 페이지에 자동으로 추가하지 않고 별도 분석으로 제공.
